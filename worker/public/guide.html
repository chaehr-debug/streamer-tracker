플랫폼집계 항목처리 방식
치지직지난달 방송 시간, 평균·최고 시청자집계 PC 필요
Twitch지난달 이터널 리턴 카테고리 방송 시간·횟수, 평균·최고 시청자, 팔로워 증감집계 PC 필요
유튜브지난달 업로드 영상 수, 평균 조회수서버가 바로 처리

화면 구성

  • 스트리머 관리 — 왼쪽에서 추가, 목록에서 선택하면 오른쪽에 월별 기록. 목록은 드래그로 순서 변경, 관리를 누르면 여러 명 선택 삭제.
  • 지난달 전체 현황 — 플랫폼별 지난달 지표 표. 열 제목을 눌러 정렬, CSV로 내보내기로 엑셀에서 열기.
  • 스트리머 심사 (치지직 탭) — 정식 등록 전 후보를 기준에 따라 걸러내는 단계.

집계 PC (중요)

치지직·Twitch 통계 사이트는 봇 차단이 있어 서버가 직접 가져올 수 없습니다. 그래서 에이전트가 설치돼 켜져 있는 PC가 실제 Chrome으로 데이터를 가져옵니다.

① 버튼 클릭사이트에 집계 요청이 등록됨
② 집계 PC가 가져감켜져 있는 PC 중 한 대가 Chrome으로 수집
③ 결과 반영몇 초~수 분 뒤 화면에 표시

오른쪽 위 표시로 상태를 확인하세요.

집계 PC n대 연결됨집계 가능. 누르면 어떤 PC가 연결돼 있는지 보입니다.
켜진 집계 PC 없음치지직·Twitch 집계/검색이 실행되지 않습니다. 요청하면 몇 초 안에 취소되고 안내가 뜹니다. (유튜브는 정상 동작)
여러 PC에 설치해 두면 그중 켜져 있는 한 대가 처리합니다. 같은 작업을 두 PC가 중복 처리하지 않으니 많이 설치할수록 안정적입니다.

내 PC에 에이전트 설치 (Windows, 약 3분)

⬇ 설치 파일 받기  메인 화면 오른쪽 위 버튼과 같습니다.

  1. 설치 파일 StreamerTracker-Agent-Setup.cmd를 받습니다. 브라우저가 "위험할 수 있는 파일"이라고 하면 계속 / 보관을 누르세요.
  2. 받은 파일을 실행합니다. "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행.
  3. 검은 창에서 설치가 자동으로 진행됩니다. Node.js가 없으면 설치할지 물어보니 Y를 누르세요.
  4. "설치 완료"가 나오면 창을 닫고 사이트를 새로고침 → 오른쪽 위에 내 PC 이름이 보이면 끝입니다.
설치 후 수집용 Chrome 창이 따로 하나 뜹니다. 평소 쓰는 Chrome과는 별개의 창이니 닫지 말고 최소화해 두세요.
  • 윈도우에 로그인할 때마다 자동으로 실행됩니다.
  • 같은 설치 파일을 다시 실행하면 최신 버전으로 업데이트됩니다.
  • 설치 위치: %LOCALAPPDATA%\StreamerTrackerAgent · 제거: 그 폴더의 uninstall.ps1 실행
  • 설치 파일에는 사이트 접속 키가 들어 있으니 외부에 공유하지 마세요.

치지직

스트리머 추가

  • 1명씩 추가 — 이름 검색 → 후보 중 맞는 채널 선택 → 상태·메모 입력 → 이 채널로 추가
  • 여러 명 한번에 — 한 줄에 한 명씩 이름 입력 → 일괄 검색 → 결과 확인(후보 변경·제외 가능) → 선택한 항목 모두 추가

집계

  • 한 명: 스트리머 선택 → 지난달 집계 실행
  • 전체: 오른쪽 위 치지직 전체 집계 실행 (인원에 따라 수 분)

Twitch

  • 지역 탭(NA/EU · SA/ASIA · JP · TW)별로 관리합니다.
  • 추가: 이름(표시용)과 트위치 핸들(twitch.tv/핸들의 핸들) 입력. 여러 명은 한 줄에 이름,핸들.
  • 집계: 지역 탭을 고른 뒤 Twitch [지역] 집계 실행. 지표는 Eternal Return 카테고리 방송만 집계합니다(팔로워 증감은 전체 기준).
  • 추가 직후 지난달 집계 실행으로 핸들이 맞는지 확인해 보세요.

유튜브

  • 추가: 이름과 채널 링크(채널 주소, @핸들, 영상 링크 모두 가능).
  • 집계: 지난달 업로드한 영상 수와 그 영상들의 평균 조회수. 조회수는 지금 기준이라 시간이 지나면 늘어날 수 있습니다.
  • 집계 PC 없이 서버가 바로 처리합니다. 치지직·Twitch 스트리머도 유튜브 링크가 있으면 유튜브 지난달 집계를 쓸 수 있습니다.

스트리머 심사 (치지직)

  1. 치지직 탭 → 스트리머 심사 → 후보 이름을 검색해 심사 명단에 추가
  2. 지난달 활동 집계 실행
  3. 지난달 이터널 리턴 카테고리 기준 방송 30시간 이상 + 평균 시청자 30명 이상이면 자동으로 정식 스트리머(크리에이터)로 등록되고 명단에서 빠집니다. 미달이면 기준 미달로 남습니다.

문제 해결

증상해결
"켜진 집계 PC가 없어 요청을 취소했습니다"집계 PC가 하나도 안 켜져 있습니다. 내 PC에 에이전트를 설치하거나, 설치된 PC를 켠 뒤 다시 시도하세요.
"앞에 처리 중인 작업이 n개…"다른 집계(전체 집계 등)가 먼저 돌고 있습니다. 끝나면 자동으로 이어서 처리됩니다.
설치했는데 내 PC가 안 보임%LOCALAPPDATA%\StreamerTrackerAgent\logs\agent.log 마지막 줄을 확인하고, 설치 파일을 다시 실행해 보세요.
"Chrome 또는 Edge를 찾지 못했습니다"Chrome을 설치한 뒤 설치 파일을 다시 실행하세요.
"검색 결과가 없습니다"치지직 표시 이름과 정확히 같은지 확인하세요. 띄어쓰기·특수문자 차이로 못 찾는 경우가 많습니다.
보안 확인(체크포인트) 오류수집용 Chrome 창에서 viewership.softc.one을 한 번 직접 열어본 뒤 다시 시도하세요.
Twitch 지표가 0지난달 이터널 리턴 카테고리 방송이 없으면 0입니다. 핸들이 맞는지도 확인하세요.
